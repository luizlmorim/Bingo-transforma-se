<h1>🎲 Bingo da Alegria</h1>

<p>Um projeto simples desenvolvido em JavaScript (Node.js) que simula um sorteio de números de um bingo. O programa permite realizar sorteios aleatórios sem repetição, consultar os números já sorteados e verificar quantos números ainda restam no jogo.</p>

<h2>📌 Objetivo</h2>

Este projeto foi criado para praticar conceitos fundamentais de JavaScript, como:

<ul>
  <li>Variáveis e constantes</li>
  <li>Funções</li>
  <li>Estruturas de decisão (if/else)</li>
  <li>Estruturas de repetição (for)</li>
  <li>Arrays</li>
  <li>Métodos de arrays (push() e splice())</li>
  <li>Geração de números aleatórios (Math.random())</li>
  <li>Entrada de dados pelo terminal utilizando o módulo readline</li>
</ul>
